# campanha-5e-assets

Imagens de apoio para uma campanha pessoal de D&D 5e (tokens de NPC, mapa regional, vila e um handout), geradas por IA (Google Flow) e hospedadas aqui só para serem usadas como URL em uma mesa virtual. Uso pessoal, não comercial.

Inclui tokens de criaturas e versões de jogador de dois mapas feitos a partir de material publicado da Wizards of the Coast (Dragon Delves), para uso privado na mesa. Direitos pertencem aos respectivos autores.
